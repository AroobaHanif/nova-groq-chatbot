I built NOVA, a professional AI chatbot web app designed for focused learning, coding, and creative exploration. The project uses Python, Streamlit, and the official Groq API to deliver a fast, responsive chat experience.

Key features include live Groq model discovery, customizable personas and system prompts, streaming responses with conversation-memory controls, and secure TXT/JSON/Markdown exports that never include the API key. I also added shared-key protection, graceful API error handling, responsive dark-mode styling, and a clean multi-chat workflow.

Building NOVA strengthened my understanding of API integration, session state, safe secret handling, and designing interfaces that make AI feel approachable. This project is part of my AI training at Corvit Rawalpindi.
